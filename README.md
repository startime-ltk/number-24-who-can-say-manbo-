# 曼波语翻译器 (Manbo Translator)

一个命令行小玩具：输入任意中文，自动替换为等字数的"曼波语"。

## 效果示例

```
请输入一句中文：今天天气真好
输入字数：6
替换结果：哈基米曼波我我南北绿豆曼巴
```

## 词汇表

| 词汇 | 字数 |
|------|:----:|
| 曼波 | 2 |
| 哈基米 | 3 |
| 我 | 1 |
| 南北绿豆 | 4 |
| 曼巴 | 2 |

程序会随机拼接这些词，直到凑够输入的中文字数。

## 编译运行

```bash
gcc -o manbo manbo.c
./manbo
```

Windows 下用 MinGW 或 Visual Studio 编译均可。

## 使用

1. 输入任意中文
2. 程序统计字数，用曼波语词汇随机拼接等长输出
3. 输入「拜拜」退出

## 文件

- `manbo.c` — 完整源码，约 180 行纯 C，无外部依赖
